# 参加&協力
もし参加や協力があるならば、誤字脱字の指摘でも大歓迎です!  
オープンソースの力で僕たちの角頭歩戦法を育てましょう!  

## 題名変更の可能性
もし協力者が増えたら「僕の角頭歩戦法」という題名が「僕らの角頭歩戦法」と改名されます。  
誤字脱字指摘等を含め貢献された方6人を越えたら「ら」を採用します。  
希望者は参加者として記載します。
